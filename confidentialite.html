Confidentialité et stockage des données

Informations sur cette version de démonstration. Mise à jour : 8 octobre 2026.

Où sont enregistrées les données ?

La progression, les résultats des quiz, les objectifs de stage, les notes et les préférences sont enregistrés dans le stockage local (localStorage) du navigateur utilisé. Cette version ne dispose pas de compte utilisateur ni de synchronisation entre appareils.

Qui peut voir mes données ?

Le code du site n’envoie pas ces notes à une base de données du projet. Elles restent toutefois accessibles aux personnes utilisant le même profil de navigateur et peuvent être perdues si ses données sont effacées. N’y saisissez aucun nom de patient, date de naissance, adresse, donnée de santé ou information de stage permettant d’identifier une personne.

Services externes

Le site est hébergé par GitHub Pages, dont l’infrastructure peut traiter des données de connexion techniques. Certaines planches d’anatomie proviennent de ressources externes, notamment Wikimedia Commons, susceptibles de recevoir une requête lorsque l’image est chargée. Les liens vers des ressources tierces ouvrent leurs propres sites et politiques de confidentialité.

Chatbot

L’assistant actuel est local : il recherche dans les contenus présents sur le site. Il ne se substitue pas à un professionnel de santé et ne permet pas de transmettre de données de patients.

Supprimer mes données

Vous pouvez effacer les données du site depuis les paramètres de stockage de votre navigateur. Cette suppression est irréversible. Vous pouvez également exporter puis effacer les données enregistrées par cette plateforme avec les commandes ci-dessous.

Gérer mes données locales

Ces actions concernent uniquement ce navigateur. Le fichier exporté peut contenir des notes personnelles : conservez-le dans un endroit sûr.
